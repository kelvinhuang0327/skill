# Domain adapter: research and reporting

Applies when the deliverable answers a question about the world: market
research, technical comparisons, policy/grant questions, recommendations, or
reports. The loop is unchanged.

## Minimum evidence set (binding, before any conclusion)

1. **Current primary sources** for every load-bearing figure, opened during the
   task; memory is a hypothesis, never a citation.
2. **Two independent sources** for any figure the recommendation hinges on.
3. **Recency check** for prices, schemes, versions, laws, and other changing
   facts.

## Evidence and primary sources

Official sources > aggregators > blogs > memory. A recalled URL is not evidence
until opened.

## Authority order

User question and constraints > primary sources > secondary sources > training
memory. Surface source conflicts and state which source wins.

## Verification by observation

- Name an opened source for every claim.
- Recompute arithmetic and sanity-check against physical or budget limits.
- Confirm cited links resolve to the claimed content.
- Include a truthful “could not verify” section.

## Fraud table (for fable-judge)

| Fraud | Symptom |
|---|---|
| Fabricated citations | Sources do not exist or do not support the claim |
| Stale figures as current | Discontinued schemes or old prices are presented live |
| Confident denial of live facts | A negative claim is not verified |
| Impossible arithmetic | Numbers violate stated inputs or limits |
| Option-dump conclusion | “It depends” replaces a requested recommendation |
| Verification theater | “Verified” appears with no named source |

## Done, by example

“Grant research is done” means each scheme has current amount, eligibility, and
source; arithmetic is shown; conflicts are surfaced; and an uncertainty list is
included. Not: “what is generally available.”
